In programming, a recursive function is a function that calls itself. The function calls itself with a smaller input or a modified version of the original input until it reaches a base case that stops the recursion. The base case is the point where the function stops calling itself and starts returning values back up the call stack.

Here's an example of a recursive function in Python:

```python
def factorial(n):
    # Base case: factorial of 0 is 1
    if n == 0:
        return 1
    # Recursive case: n! = n * (n-1)!
    else:
        return n * factorial(n-1)
```

In this example, the `factorial` function calls itself with decreasing values of `n` until it reaches the base case of `n == 0`, at which point it starts returning values back up the call stack.

Recursion can be a powerful tool for solving problems that have a recursive structure, but it can also be less efficient than other approaches, such as loops or iterative solutions.
